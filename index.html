4Paradigm × Gradient NetworkDe facto tech lead + product

Darvin — decentralized AI compute & evaluation platform

An AI infrastructure project co-incubated by 4Paradigm and Gradient Network that abstracts AI tasks, data annotation, model evaluation, K8s compute scheduling and on-chain incentives into reusable, general-purpose task subnets.

  • Led the human-in-the-loop evaluation data platform: async task flows, review flows, webhooks, short-lived tokens, idempotent result pulls and auto-scoring.
  • Designed multi-tenant architecture with RBAC, identity mapping, audit logs and state machines across publishers, annotators, reviewers and operators.
  • Planned a unified K8s task runtime and scheduling across heterogeneous GPU / NPU and domestic compute.
  • Proposed an agent-friendly CLI — stable commands, structured output, step reports — as the operating layer for natural-language agents.

AI code-review audit agent

An enterprise R&D-governance agent that turns commits into structured context, judges risk, routes to human review and feeds a management dashboard.

  • 7B-class code model (CodeQwen1.5-7B-Chat) for semantic summaries and risk explanations; deterministic rules filter first to cut inference cost.
  • Risk grading, attribution and human confirmation; batch and incremental scanning wired into internal repos and pipelines.
Supported tens of millions of RMB in R&D cost savings.

BrandNative Agent Harness

A multimodal agent that works like a brand-aware marketing assistant: it reads brand material first, then picks the right models for copy, images, music and video — and improves from feedback.

  • Loop: understand task → read brand source → call tools → check result → record feedback.
  • Harness for decomposition, candidates, quality checks, retries and run logs across ~9 model channels incl. an evaluator.
